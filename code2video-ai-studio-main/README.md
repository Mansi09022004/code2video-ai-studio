# 🎬 Code2Video AI Studio

An AI-powered educational platform that automatically converts Python source code into narrated, cinematic tutorial videos with step-by-step visualizations.

## ✨ Features

- 🤖 **AI-Powered Code Analysis** - Uses Groq LLaMA 3.3 70B to understand Python code
- 🎥 **Automatic Video Generation** - Converts code to MP4 with synchronized visuals
- 🎙️ **Multilingual Narration** - Supports English, Hindi, Marathi, Telugu
- 📝 **Subtitle Generation** - Auto-generates SRT subtitle files
- 🔍 **Algorithm Visualization** - Dynamic visualizations for sorting, searching, recursion
- 💬 **AI Doubt Assistant** - Built-in AI tutor for code questions
- ⭐ **Favorites & History** - Save and track your generated videos
- 📊 **Feedback System** - Rate and comment on videos
